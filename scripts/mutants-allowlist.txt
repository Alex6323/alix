# Mutation-miss allowlist. scripts/mutants_allowed.py reconciles
# cargo-mutants misses against this file: a run stays red unless every
# miss matches an entry here. Entries document argued residuals; the
# mutants still run every sweep, so red means NEW information.
#
# Down from twenty-four groups. Alex ruled
# 2026-08-06 that the only admissible reason is "it really cannot be
# tested", so everything merely awkward was seamed and killed instead:
# the uuid mixer became a pure function of its seed (11 killed), the
# pairing host became a parameter (1), and a child's outcome separated
# from spawning it (4). What remains is genuinely untestable, by one of
# four proofs:
#
#   EQUIVALENT    output identical for every input, provably.
#   UNREACHABLE   the branch cannot be entered; kept as a loud guard.
#   UNOBSERVABLE  the value has no consumer on this path.
#   IO-LEAF       nothing but a syscall remains; the logic it feeds is
#                 tested through a seam.
#
# No entry may say "no test covers this yet". That is a missing test.
#
# Both survivor classes are reconciled here: a MISS (the tests passed
# under the mutant) and a TIMEOUT (the mutated tests hung). Timeouts need
# entries too, because cargo-mutants reports a timeout in preference to a
# miss, so one unargued timeout keeps a shard red no matter how well its
# misses are argued. Alex ruled 2026-08-10: a hang counts as detection
# ONLY where the mutant is proven NON-TERMINATING at that site. Every
# other hang stays red, because a timeout is evidence about the mutant,
# not about the tests. The 2026-08-09 nightly is why: of its four hangs,
# two were real, one mutant was already caught, and one was a plain miss
# that the hang hid (`deck_due`, which runs green in 16s).
#
# Every group states its CLASS, because "residual" must never be read as
# "impossible". Five classes, only the first two of which are unfixable:
#
#   EQUIVALENT   no test can distinguish the mutant: output is identical
#                for every input. Genuinely unkillable.
#   NON-TERMINATING  the only survivor class for a TIMEOUT. The mutated
#                expression is a loop's only advance, so the loop never
#                exits and hanging is the only outcome any budget can
#                produce. Proof is per SITE, never per operator: the same
#                substitution terminates wherever something else advances
#                the counter. cargo-mutants usually supplies the contrast
#                itself, as a sibling mutant on the same line that
#                terminates and is caught. Prefer deleting the manual
#                counter loop (an iterator expression has no such site) to
#                writing the entry: that is what closed both of the
#                2026-08-09 hangs, and it leaves nothing to argue.
#   DELIBERATE   unreachable code kept on purpose (defence in depth). The
#                mutant is the price of the safety net; killing it means
#                deleting the net.
#   DEAD-PATH    the mutated value has no consumer on this path, but the
#                code is shared with paths where it matters, so it cannot
#                be removed here.
#   NEEDS-SEAM   killable, but only by adding a testing seam to production
#                code (injectable randomness, an injectable host lookup, a
#                spawn indirection). NOT a wall: an open decision, and one
#                Alex can overturn at any time.
#
# Entry forms, both exactly as cargo-mutants prints the survivor:
#   <file>: <mutation description>          argued CLASS (any line)
#   <file>:<line>: <mutation description>   single argued site (rots
#                                           loudly via the stale note
#                                           when the line moves)
# Every entry group MUST carry its argument in the comment above it.
# An entry without an argument, or whose code has changed since the
# argument, does not belong here. Remove an entry the moment a
# legitimate law kills its mutant; the "matched nothing" note on a
# whole-tree sweep of its shard is the removal reminder.
