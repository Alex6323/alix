## Why does TCP open with a three-way handshake?
So both sides learn that the other's sequence number arrived.
> [!NOTE]
> Two messages would leave the server unsure its own SYN was received.

## What is a monad, in one sentence?
A type with a way to wrap a value and a way to chain functions that
return wrapped values.
> [!NOTE]
> The laws matter more than the definition: identity and associativity.
